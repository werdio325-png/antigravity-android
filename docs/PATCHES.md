# AArch64 Binary Patching Pipeline (`patches/`)

This document details the low-level AOT (Ahead-of-Time) binary patch pipeline used in **Antigravity for Android** to adapt the official Google `language_server` (64-bit ELF AArch64) to the Android Linux runtime.

---

## 1. Principles & Design Constraints

1. **No Fixed Offsets:** The pipeline never hardcodes byte offsets. Patch locations are discovered dynamically via instruction signatures, regex patterns, or by parsing the Go `pclntab`.
2. **Fail-Closed Verification:** If any signature count deviates from expectations (`expected_counts`), patching terminates immediately without saving to disk.
3. **Idempotent:** Re-running the pipeline on an already-patched binary verifies the applied signatures and exits cleanly with status `already`.
4. **Staging Isolation:** The pristine archive binary (`core/language_server`) is never touched; all operations run against `build/staging/language_server`.

---

## 2. Patch Groups

```
patches/
├── groups/
│   ├── syscalls/      # Android Seccomp Bypass (faccessat2, fchmodat2)
│   ├── gates/         # Enterprise Auth & CLI Gate Bypass
│   ├── resolv/        # Length-preserving DNS Resolver Rewrite
│   └── auth/          # OAuth Redirect URL Deep Link Rewrite
```

### A. Android Seccomp Bypass (`groups/syscalls`)
- **Problem:** Modern Linux kernels support `faccessat2` (syscall #439 on arm64) and `fchmodat2` (syscall #452 on arm64). Android's seccomp filter intercepts these syscalls with `SECCOMP_RET_TRAP`, killing the process immediately with `SIGSYS`.
- **Solution:** Rather than blind byte replacement across the 174 MB binary, the module parses the Go runtime `pclntab` header:
  1. Validates `pclntab` by locating the `runtime.memmove` test symbol.
  2. Resolves function boundaries for `syscall.faccessat2` and `syscall.fchmodat2`.
  3. Replaces the `MOVZ X0, #imm` instruction loading the syscall number:
     - `syscall.faccessat2`: `MOVZ X0, #439` (`0xe0 0x36 0x80 0xd2`) $\longrightarrow$ `MOVZ X0, #48` (`0x00 0x06 0x80 0xd2`) $\to$ retargets to `faccessat`.
     - `syscall.fchmodat2`: `MOVZ X0, #452` (`0x80 0x38 0x80 0xd2`) $\longrightarrow$ `MOVZ X0, #53` (`0xa0 0x06 0x80 0xd2`) $\to$ retargets to `fchmodat`.

### B. Eligibility & Auth Gate Bypass (`groups/gates`)
- **Problem:** Embedded account validation checks (`CLI gate` and `authclient.(*EnterpriseAuthValidator).Validate`) restrict engine execution unless verified.
- **Solution:** Patches the branch validation registers:
  1. **CLI Gate (2 sites):**
     - Raw: `ldrb w1, [x0, #8]` (`01 20 40 39`) + `tbnz w1, #0`
     - Patch: `mov w1, #1` (`21 00 80 52`)
  2. **Manager Gate (1 site):**
     - Raw: `ldrb w3, [x0, #8]` (`03 20 40 39`) + `tbz w3, #0`
     - Patch: `mov w3, #1 ; strb w3, [x0, #8]` (`23 00 80 52 03 20 00 39`)
- **Safety Invariant:** Channelz gRPC structures use register `w2` and are strictly excluded.

### C. DNS Resolver Rewrite (`groups/resolv`)
- **Problem:** When running with `GODEBUG=netdns=go`, the Go resolver attempts to open `/etc/resolv.conf`, which does not exist on Android.
- **Solution:** Exactly 16-byte length-preserving string rewrite:
  - Raw: `/etc/resolv.conf` (16 bytes)
  - Patch: `etc//resolv.conf` (16 bytes)
  - The leading `/` is removed, making the path relative. Because `CoreLauncher.java` sets the process working directory to `<filesDir>`, the core resolves `<filesDir>/etc/resolv.conf` dynamically generated by `NetworkConfigWriter.java`.

### D. OAuth Deep Link Rewrite (`groups/auth`)
- **Target:** `https://antigravity.google/auth-success?app=%s` (46 bytes)
- **Patch:** `antigravity://auth-success?app=%s#############` (46 bytes, padded with `#` URL fragment markers).
- **Guards:** Ensures critical authentication endpoints (`oauth-callback`, `accounts.google.com/o/oauth2/auth`) remain unaltered.

## 3. Extending the Patch Pipeline

To add a new patch group:
1. Create `patches/groups/<name>/`:
   - `signatures.py`: Constants, opcodes, expected match counts.
   - `analyze.py`: In-memory scanner operating on `bytearray`.
   - `module.py`: Implements `run(target_path, verify, dry_run, allow_missing, log)`.
2. Register the module in `patches/patch_lib/runner.py` under `GROUP_MODULES`.
3. Add schema declarations to `patches/manifest.json`.
4. Add automated unit tests to `patches/tests/test_patches.py`.
