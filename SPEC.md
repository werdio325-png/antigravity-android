# AGY v2 — build & interface spec (authoritative)

All agents must follow this.
`env/` is out of scope — never modify, only reference.

## Hard rules
1. **Behavior is ported 1:1** from the original where it is live code. This is a
   restructure, not a rewrite. Do not change binary-patch offsets/signatures.
2. **Drop only dead code** listed in `docs/DEADCODE.md` (create/extend as you go).
   If unsure whether something is dead, keep it.
3. One responsibility per file. Names are descriptive, lower-case for
   shell/py/js, CamelCase for Java.
4. No new runtime dependencies. No frameworks.
5. Every shell file must pass `bash -n`. Every `.py` must pass
   `python3 -m py_compile`. Every `.js` should pass `node --check` if node exists.

## Config (already written)
- `config/app.env` — PKG, PKG_DEV, APP_NAME, APP_NAME_DEV, PORT, PORT_DEV,
  OAUTH_SCHEME, CORE_VERSION, MIN_API, TARGET_SDK.
- `config/paths.env` — AGY_HOME + $AGY_HOME-relative heavy inputs.
- `config/tools.env` — KEY_ALIAS/KEY_PASS/STORE_PASS.
Sourced with `set -a` by `build/lib/paths.sh`.

## Layer interfaces (frozen)

### patches
Entry stays: `python3 patches/patch_runner.py <binary> [--verify|--dry-run|--allow-missing|--manifest P|--no-manifest]`.
`patch_lib/runner.py` owns `GROUP_MODULES`, `run_pipeline(...)`, `main(argv)`.
Each group module keeps `def run(target_path, verify=False, dry_run=False, allow_missing=False, log=print) -> (bool, dict)`.
Group module path: `patches/groups/<name>/module.py`. runner loads it by import.
`movz_x0`, `_selftest` (resolv/auth) names preserved.

### web
Upstream files stay at the **root of `web/`** (`main.js`, `prism_bundle.js`,
`compiled_tailwind.css`, `jetbox.css`, `diff_worker.js`, `audio_processor.js`,
`symbols-icons/`, `*.mp3`, `*.png`, `antigravity-icon.png`) because `main.js`
loads them from the served root (`/diff_worker.js`, `/symbols-icons`, ...).
Our split sources live under `web/src/**`; generated bundles under
`web/generated/**`; `web/index.html` references `./generated/<out>` plus the
upstream root files. The concatenator is `web/build.sh`. Native injection of
`startup_ready` targets `./generated/patches/startup_ready.js`.

`web/src.manifest` (parser = `web/build.sh`):
```
bundle bridge.core.js
src/core/namespace.js
src/core/config.js
...

bundle bridge.cache.js
src/cache/namespace.js
...
```
Blank line between bundles. `bundle <out>` starts a bundle; following non-empty
lines are input paths relative to `web/`, concatenated in order into
`web/generated/<out>`. A `;` at line start is a comment.
Concatenation wraps inputs in **no** wrapper — each src file is a fragment that
relies on the bundle's shared scope. Fragments share the bundle IIFE: the first
fragment must open nothing, and each fragment is plain top-level JS that the
bundle's namespace file has set up as `window.__agCore` / `window.__agCache`
(or similar). Simpler rule for agents: **each bundle is one IIFE**; `build_web.sh`
emits `(function(){` + files + `})();` when the manifest marks the bundle with
`iife`, e.g. `bundle iife bridge.core.js`. Use `iife` for core/cache and for
each patch bundle. index.html/native reference `web/generated/<out>`.

### build
`build.sh` (thin): set flags, source `build/lib/*.sh` then `build/phases/*.sh`
in lexical order, all **sourced** (not executed) so `die`/vars propagate.
Phase files named `NN-name.sh`. Provide functions:
`build/lib/log.sh: log(), die()`; `build/lib/prereqs.sh: need()`, tool checks;
`build/lib/flags.sh: parse_args()`; `build/lib/paths.sh` sources config + sets
all path vars.

Generated by build:
- `app/gen/com/agy/BuildConfig.java` (from app.env)
- `build/res/values/gen.xml` (app_name, https_server_port, oauth_scheme)
- dev manifest `build/AndroidManifest.xml` (package=PKG_DEV, label=APP_NAME_DEV)
- `web/generated/**`
- assets + APK under `build/`, `dist/agy.apk` / `dist/agy-dev.apk`

`app/AndroidManifest.xml` always uses **fully-qualified** class names
(`com.agy.ui.MainActivity`, `com.agy.core.CoreServerService`,
`com.agy.ui.launcher.LauncherDarkActivity`, `.LauncherLightActivity`).
Dev build only rewrites `package="com.agy"` and the label; class names unchanged.

`build/tools/gen_android_config.py <app.env> <outdir>` writes BuildConfig.java
and the res gen.xml.

## Verification (orchestrator runs these)
- `bash -n` all `.sh`; `python3 -m py_compile` all `.py`.
- `python3 patches/patch_runner.py /tmp/opencode/core-copy --dry-run` then
  `--verify` after applying; fail-closed.
- web: run `build/tools/build_web.sh`, confirm `web/generated/*` exist, non-empty.
- full: `bash build.sh --dev`, `apksigner verify`, and sha256 of the staged
  patched core must equal the core extracted from old `dist/agy-dev.apk`.
